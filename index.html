Tải Excel · Quét mã vạch · Đối chiếu nhiều file cùng lúc

1. Tải file Excel

Chọn tối đa 5 file Excel. File đầu tiên mặc định là File tổng; các file sau là chương trình khuyến mãi. Mã trùng giữa các file sẽ hiển thị thành các kết quả riêng.

Chưa tải file dữ liệu.

Chọn cột mã vạch

File được xử lý ngay trong trình duyệt, không tải lên máy chủ. Chỉ đọc sheet đầu tiên. Không đưa file chứa dữ liệu nhạy cảm lên nơi công khai.

2. Quét hoặc nhập mã vạch

Đưa mã vạch vào trong khung xanh
Hãy tải file dữ liệu hợp lệ trước khi tra cứu.
